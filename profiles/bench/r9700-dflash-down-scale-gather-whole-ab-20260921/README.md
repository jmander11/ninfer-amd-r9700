No argument means CPU preflight. Preparation binds the current commit, changed
implementation, admitted direct result, exact artifact/corpus, both build caches,
archives and executables. Preflight runs host routing/workspace/report tests and
checks the benchmark's embedded candidate/activation/incumbent instruction and
resource profiles against direct qualification. No rebuild, sudo or GPU reset.

Whole P128/D64, C1, three measured repetitions and one warmup, Device Graph on.
Ordinary controls from both builds must expose the same 65 public greedy tokens.
K4/W5 runs control/candidate/candidate/control; K5/W6 runs the reverse. Every
repetition must match ordinary tokens, and speculative accounting must match
within each width. Workspace capacity cannot grow or overflow; graph memory must
fit allowance. Both decode and whole time require every launch-order median win,
paired ratio mean+2SE below one, median ratio <=0.99 and order spread <=0.02.
This is a bounded material-win screen, not a precision confidence interval.

First functional failure stops the queue. A valid timing loser closes
completed/rejected with exit zero; success only permits promotion review, not
automatic production routing or recipe selection. Results, process receipts,
closure and checksum manifest are create-only under results/. Never rerun or
overwrite an attempt. The sealed September 19 split-K campaign remains untouched.
